# miniOrange Grok Plugins

Grok Build plugins published by miniOrange. The catalog lives in
[`.grok-plugin/marketplace.json`](.grok-plugin/marketplace.json).

## Plugins

- **[mcp-server-for-wordpress](plugins/mcp-server-for-wordpress)**: connects
  Grok to a WordPress site through the miniOrange MCP gateway
  (`https://gateway.miniorange.ai/v2/mcp`), exposing WordPress Abilities API
  actions as tools.
